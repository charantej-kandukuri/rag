# Vocabulary

1. dedupe
Dedupe (short for deduplication) is the process of finding and removing unnecessary, repeated copies of files, blocks of data, or database records, keeping only a single instance.

2. fan-out
Fan out means to spread, branch or distribute outward from a single central point into multiple directions, tasks, or components.

Software Engineering & System Design:
- Defination: An architechtural pattern where a single source, message or task produces and sends multiple parallel sub-tasks or messages to different destinations at the same time.
- Example: When a user uploads a video, the system fans out the work into parallel jobs—such as generating a thumbnail, scanning for safety, and transcoding into different resolutions (480p, 720p, 1080p).
- [more on medium article](https://medium.com/@kapoorjasdeep/fan-out-and-fan-in-the-unsung-heroes-of-system-design-2f8a46933518)


3. ad-hoc
Ad hoc is a Latin phrase that literally means "for this" or "for this purpose."

4. TL;DR stands for "too long; didn't read"

5. prose
Prose simply means language that follows the natural patterns found in everyday speech.

6. needle in a haystack - idiom
The idiom "a needle in a haystack" means something that is extremely difficult or nearly impossible to find, usually because the object is very small and the area or collection you have to search is way too large.
